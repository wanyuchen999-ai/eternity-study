# Eternity 学习台 📚

一个为学生打造的**本地优先**学习网页应用：番茄钟、待办、AI 学习台（课堂录音整理 / AI 对话框架 / AI 学习规划 / 笔记归纳）、背单词、智能录题刷题、错题本、考试倒计时、多用户档案、主题换色。

所有数据保存在**你自己的浏览器**里，无需注册、无需服务器；**AI 密钥由每个用户各自填写**（代码里不内置任何密钥），只存在各自浏览器本地。

## 面向所有人使用（部署）

应用是纯静态网页，构建后可免费部署到 Vercel / Netlify / GitHub Pages 等：

```bash
npm run build   # 产出 dist/ 目录，把整个目录上传即可
```

部署后每个访问者：选一个自己的用户名 → 到设置里填自己的 AI 密钥 → 开始用。数据互相隔离（同一浏览器内按用户名区分；不同设备各自独立）。

## 快速开始

```bash
npm install
npm run dev        # 开发模式，浏览器打开 http://localhost:5173
npm run build      # 生产构建（输出到 dist/）
npm run preview    # 预览构建产物
```

> 注：本机若启用了「应用程序控制 / Smart App Control」拦截 rollup 原生模块，请保持使用 vite 4.x（本项目已锁定 vite@4.5，rollup 为纯 JS 版本，可正常构建）。

## 首次使用（重要）

1. 打开应用 → 左下角 **设置**
2. 点一个常用服务商一键填入推荐配置（智谱 AI 有免费模型，学生够用）
3. 填入 **API 密钥**，点「测试连接」
4. 完成后：AI 学习台、智能录题、AI 摘词全部解锁

| 服务商 | API 地址 | 对话模型 | 视觉模型 | 转写模型 |
|---|---|---|---|---|
| 智谱 AI | `https://open.bigmodel.cn/api/paas/v4` | glm-4-flash（免费） | glm-4v-flash（免费） | glm-asr |
| DeepSeek | `https://api.deepseek.com/v1` | deepseek-chat | 不支持 | 不支持 |
| Kimi | `https://api.moonshot.cn/v1` | moonshot-v1-8k | moonshot-v1-8k(v) | 不支持 |
| 通义千问 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | qwen-plus | qwen-vl-plus | 不支持 |
| OpenAI | `https://api.openai.com/v1` | gpt-4o-mini | gpt-4o-mini | whisper-1 |

- 任何 OpenAI 兼容服务都可以：改 API 地址和模型名即可
- 若浏览器控制台出现 **CORS 报错**，说明该服务商不允许网页直连，请换服务商（智谱 / DeepSeek / OpenAI 均可直连）
- 不支持语音转写的服务商：录音整理可先用其他工具转写，再粘贴文本

### 本地演示模式（无需密钥）

没办 API 密钥也想先体验 AI 功能？开一个终端运行：

```bash
node scripts/mock-ai-server.mjs
```

然后到「设置」点「本地演示（假 AI）」——学习规划、笔记归纳等功能会用固定脚本回复，方便熟悉流程（回复内容是写死的示例）。

## 功能地图

| 模块 | 说明 |
|---|---|
| **首页** | 今日专注 / 待办 / 单词任务 / 考试倒计时 / 周专注图表 |
| **多用户** | 每人一个用户名 + 头像，数据完全隔离，侧边栏一键切换；支持改名 / 删除；旧数据自动迁移 |
| **番茄钟** | 25+5 可调、轮次圆环、科目标签、提示音、切页继续计时、7 天统计 |
| **待办** | 优先级、科目标签、截止日期、逾期标红、双击改名、四类筛选；支持接收 AI 自动写入的学习计划 |
| **AI 学习台** | ① 课堂录音→转写→整理成结构化笔记（**生成后自动存入笔记库**）② AI 对话四种模式（自由提问 / 逻辑框架 / 费曼讲解 / 出题自测）③ **学习规划**：告诉 AI「我想学 Python」，它会和你确认周期，生成按天/周的计划，并**自动把任务写进待办**（含截止日期，可一键撤销；调整计划自动覆盖）④ 批量笔记归纳成「问答背诵框架 / 一页逻辑框架 / 考点清单」，**自动落库**，问答可直接转题库 ⑤ 笔记库（搜索 / 编辑 / 导出 .md） |
| **背单词** | 内置四级示例词库；导入 txt/csv/json 词库；AI 从文章摘词建库；每日新词 + 艾宾浩斯复习（1/2/4/7/15/30 天）；发音朗读；学习打卡统计 |
| **题库** | 图片截图/拍照 → AI 识别题目（或文本解析、手动录入）→ 核对入库 → 随机刷题（单选/多选/判断/填空/简答）→ 错题自动进错题本，支持重做与「已掌握」 |
| **设置** | **7 款马卡龙主题**（靛蓝/樱花粉/天空蓝/薄荷绿/葡萄紫/蜜桃橙/极简黑白，白底+单主题色，即点即换）、AI 配置与测试、番茄偏好、数据导出 / 导入 / 清空 |

### 词库导入格式（任选其一）

```
abandon  v. 放弃
access, n. 通道；获取
```
或 CSV：`单词,释义`，或 JSON：`[{"term":"abandon","definition":"v. 放弃"}]`

## 数据与隐私

- 数据全部存于浏览器 localStorage，**换浏览器/清缓存前请先在「设置 → 数据管理」导出备份**
- 导出的 JSON 含 AI 配置，注意保管
